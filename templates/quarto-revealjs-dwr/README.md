# DWR Quarto RevealJS template

Use this template for internal presentation decks that need a clean DWR-aligned visual treatment.

## Start a deck

1. Copy this directory into the folder for the meeting or project.
2. Rename `template.qmd` to a descriptive filename.
3. Update the YAML title, subtitle, and date.
4. Render with `quarto render your-deck.qmd`.

The shared `_quarto.yml` supplies the RevealJS format, slide numbering, DWR logo, and theme. The colors in `dwr.scss` are an accessible, DWR website-inspired blue, water blue, gold, and sage palette. Keep the logo asset and the configuration file together when copying the template.

The included color DWR seal is cropped from DWR’s [official logo image](https://water.ca.gov/images/dwr-logo-new.png).
